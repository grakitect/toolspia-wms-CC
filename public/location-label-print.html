로케이션 마스터

아래 목록은 WMS 본체의 "로케이션 관리 / 등록"에 등록된 로케이션을 그대로 불러온 것입니다. 여기서 직접 추가/삭제해도 본체 데이터에는 반영되지 않으며, 다음 새로고침 시 본체 목록으로 되돌아갑니다.
임시로 추가 (본체에 없는 코드도 지금만 인쇄하고 싶을 때) 전체 로케이션 코드(예: A01-01-101)를 입력하면 마지막 "-" 기준으로 랙코드(A01-01)와 단(101)을 자동으로 인식합니다.
엑셀에서 로케이션 코드가 있는 셀들을 드래그로 선택 후 복사(Ctrl+C)하여 아래 칸에 붙여넣으세요. 한 줄에 코드 하나씩 인식합니다. 또는 CSV/TXT 파일을 업로드하세요.

용지 설정

작은 라벨 프린터를 쓰신다면 필수: 프린터 드라이버 용지 크기 설정
브라우저는 @page size를 지원하지만, 프린터 드라이버가 그 크기를 모르면(목록에 없으면) 인쇄 시 오류가 나거나 A4로 강제 대체됩니다. A4/공용 프린터라면 대부분 문제없지만, 소형 라벨 프린터는 드라이버에 이 크기를 먼저 등록해야 합니다.
설정 경로: Windows 제어판 → 프린터 및 스캐너 → 해당 프린터 → 인쇄 기본 설정(또는 서버 속성 → 양식) → 새 용지 크기를 아래 값과 동일하게 등록
같은 랙코드를 가진 로케이션은 자동으로 한 라벨에 합쳐집니다. 랙마다 단(레벨) 개수가 달라도 됩니다.
